✅ STEP-BY-STEP INSTRUCTIONS:

┌─────────────────────────────────────────────────────────────┐
│  STEP 1: Open Your CV                                       │
└─────────────────────────────────────────────────────────────┘

   Option A: Double-click "OPEN_CV.bat" (in this folder)
   Option B: Go to "assets" folder → Double-click "cv.html"

┌─────────────────────────────────────────────────────────────┐
│  STEP 2: Your CV Opens in Browser                           │
└─────────────────────────────────────────────────────────────┘

   You should see a professional CV with:
   ✓ Your name: Jhanyn Concepcion
   ✓ Email: jhanynbivasconcepcion@gmail.com
   ✓ Blue "Download as PDF" button at top

┌─────────────────────────────────────────────────────────────┐
│  STEP 3: Generate PDF                                        │
└─────────────────────────────────────────────────────────────┘

   Two ways:
   
   🔵 Way 1: Click the blue "Download as PDF" button
   
   ⌨️  Way 2: Press Ctrl+P on your keyboard

┌─────────────────────────────────────────────────────────────┐
│  STEP 4: Print Dialog Opens                                 │
└─────────────────────────────────────────────────────────────┘

   In the print dialog:
   1. Destination: Click "Change..."
   2. Select: "Save as PDF" or "Microsoft Print to PDF"
   3. Click "Save" button

┌─────────────────────────────────────────────────────────────┐
│  STEP 5: Save Your PDF                                      │
└─────────────────────────────────────────────────────────────┘

   In the save dialog:
   1. Navigate to: jhanyn midterm exam → assets folder
   2. File name: cv.pdf
   3. Save as type: PDF Document
   4. Click "Save"

┌─────────────────────────────────────────────────────────────┐
│  STEP 6: Done! ✨                                           │
└─────────────────────────────────────────────────────────────┘

   Your CV is now saved as: assets\cv.pdf
   
   The download buttons in your portfolio will now work!

═══════════════════════════════════════════════════════════════

❓ TROUBLESHOOTING:

   Problem: CV won't open
   Solution: Right-click OPEN_CV.bat → Run as administrator

   Problem: No "Save as PDF" option
   Solution: Update your browser or use Microsoft Print to PDF

   Problem: PDF looks cut off
   Solution: In print settings, set scale to 100%
