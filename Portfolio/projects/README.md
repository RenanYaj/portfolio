## 🎯 Activity Descriptions

### Activity 1 - Personal Portfolio
- Features: Profile image, skills display, favorite quote, contact links
- Responsive design with hover effects
- Social media integration

### Activity 2 - Professional Layout
- Features: Sidebar navigation, skills table, about section
- Two-column layout (sidebar + main content)
- Professional gradient design

### Activity 3 - Interactive Card
- Features: Hover-to-reveal information
- Smooth animations
- Mobile-friendly (text visible on small screens)

### Activity 4 - Toggle Button
- Features: Interactive "About Me" button
- JavaScript show/hide functionality
- Button text changes dynamically

### Activity 5 - Dark Mode Toggle
- Features: Light/Dark theme switcher
- JavaScript theme toggle
- Smooth color transitions
- Button text updates based on current mode
